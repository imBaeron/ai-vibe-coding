# Commodity Price Monitoring System

## System Overview

The SUKI (Smart Utility & Kalakal Information) is a citizen-oriented platform that provides updated prices of common commodities from local markets, stores, and other participating sellers. It allows residents to compare prices, monitor price changes, and make informed purchasing decisions.

---

# Core Functionalities

## 1. Commodity Price Viewing

Users can browse and view the current prices of common commodities.

### Features
- Display commodity name
- Display current price
- Display unit of measurement (kg, liter, piece, dozen, etc.)
- Display store/market name
- Display location
- Display date and time of the latest price update
- Display price status (e.g., Available, Out of Stock)

### Example Commodities
- Rice
- Chicken
- Pork
- Beef
- Eggs
- Fish
- Vegetables
- Fruits
- Cooking oil
- Sugar
- Salt
- Other household necessities

---

## 2. Commodity Search

Users can quickly search for a specific commodity.

### Features
- Search by commodity name
- Search by category
- Search using keywords
- Show matching commodities as the user types

### Example
A user searches for:

`Rice`

The system displays different rice products and their prices from available local stores and markets.

---

## 3. Price Comparison

Users can compare the prices of the same commodity from different stores or markets.

### Features
- Compare prices from multiple sellers
- Sort prices from lowest to highest
- Identify the cheapest available option
- Display seller/store location
- Display price differences

### Example

| Store | Commodity | Price |
|---|---|---:|
| Market A | Regular Rice | ₱48/kg |
| Store B | Regular Rice | ₱50/kg |
| Market C | Regular Rice | ₱47/kg |

The system can highlight **Market C** as the cheapest option.

---

## 4. Category-Based Browsing

Commodities are organized into categories to make browsing easier.

### Possible Categories
- Rice and Grains
- Meat
- Fish and Seafood
- Fruits
- Vegetables
- Eggs
- Cooking Ingredients
- Beverages
- Household Essentials

Users can select a category and view the commodities under it.

---

## 5. Location-Based Price Information

The system provides price information based on the location of the store or market.

### Features
- Display store/market location
- Filter commodities by location
- View prices from nearby participating stores
- Display the municipality/barangay where the price was recorded

### Example

A user selects:

`Calbayog City`

The system displays commodity prices reported by participating markets and stores in Calbayog City.

---

## 6. Price History and Trends

Users can view how the price of a commodity has changed over time.

### Features
- View previous recorded prices
- Display price changes
- Show increase/decrease in price
- Display simple price history charts
- Show daily, weekly, or monthly trends
